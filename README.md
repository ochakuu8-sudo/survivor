# Stone Survivor — 永続スキル・階層経済版

敵を倒してGを集め、石の能力を購入するブラウザゲームです。

## 操作
- WASD / 矢印キー：移動（タッチ端末は画面ドラッグ）
- 攻撃：自動
- K / 右下のスキルボタン：スキルツリー
- K / Escape / 戻るボタン：ツリーを閉じる

ツリー表示中は戦闘が停止します。通貨・購入済み能力は次の階へ持ち越し、死亡後・リロード後も同じブラウザに保存されます。

## 成長
連射・跳弾・重量の３系統を組み合わせられます。最終強化はすべて解放でき、同時に１つを選択できます。共通強化は威力・射程・HP。購入すると即時発動し、装備操作や素材は不要です。

初段10G、中段35G、最終110G、共通15G。各系統に深層強化４段階（264、634、1521、3650G）を追加。通常部屋クリア12G、エリート25G、宝箱20Gを基準に、階層ごとに報酬×1.45（30階で倍率上限）。価格は到達階層で変動しません。敵のコインは広範囲で吸引し、戦闘部屋のクリア時にも回収します。緑の十字は一度だけHPを最大値の50%分回復します（満タンなら消費しません）。

## 開発
Node.js 22以上を推奨。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Viteの表示する /survivor/ のURLを開いてください。dist/は本番ビルドです。

## 検証
購入条件・最終強化の排他・効果の再計算・HP回復・ツリー開閉時の状態保持・階層移動・永続保存・最終形態切替・報酬倍率・報酬回収を自動テストしています。収入、敵密度、価格は初期調整値で、長時間のバランス調整は今後の試遊対象です。

保存先：ブラウザのlocalStorage（survivor.progression.v1）。別のブラウザ・端末・URLのポートとは共有されません。
