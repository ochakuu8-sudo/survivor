# Stone Survivor — ボス討伐・ループ平原版

敵を倒してGを集め、永久スキルツリーで石を強化するブラウザゲームです。壁や階段のない平原が上下左右につながります。

## 遊び方

- WASD / 矢印キーで移動。タッチ端末は画面ドラッグ。攻撃は自動です。
- K / 右下のスキルボタンで強化。ツリー表示中は戦闘が停止します。
- K / Escape / 戻るボタンでツリーを閉じます。
- 各難易度の討伐目標を達成すると、2秒の位置予告後にボスが出現します。
- ボス撃破でGを獲得し、落ちているGも全回収。HPを最大値の30%分回復します。
- 報酬画面で強化し、「次の難易度へ」で同じマップ・位置から再開します。
- 5体目のボス撃破で完全クリア。制限時間はなく、時間経過で難易度は上がりません。

ボス戦中は雑魚補充を減らします。ボス戦・出現予告中の討伐は次の難易度へ持ち越しません。後半のボスは予告付き突進に加え、方向を予告する扇状弾を使います。

## 難易度と経済（初期調整値）

| 難易度 | 必要討伐数 | 敵HP倍率 | 基準報酬倍率 | ボスHP | ボス報酬G |
|---|---:|---:|---:|---:|---:|
| 1 | 30 | 1 | 1 | 180 | 45 |
| 2 | 45 | 1.6 | 1.6 | 360 | 96 |
| 3 | 65 | 2.5 | 2.56 | 650 | 205 |
| 4 | 90 | 3.8 | 4.096 | 1050 | 430 |
| 5 | 120 | 5.5 | 6.5536 | 1650 | 983 |

通貨は整数に丸めます。ドロップ時に金額を確定するため、後から難易度を上げて回収しても値上がりしません。コイン上限に達すると価値をまとめ、消失を防ぎます。敵の通常移動速度は難易度5でも基準の1.32倍です。突進は予告付きの別行動です。

連射・跳弾・重量の3系統を組み合わせられます。最終形態は複数購入でき、同時に1つを選択します。共通強化は威力・射程・HPです。

初段10G、中段35G、最終110G、共通15G。各系統の追加強化4段階は264・634・1521・3650G。価格はノードごとに固定で、到達難易度では変動しません。

## セーブ

所持G・購入済み能力・選択中の最終形態は死亡・クリア・リロード後も保持します。戦闘は難易度1から再開します。既存の `survivor.progression.v1` をそのまま読み込むため、以前のセーブを消す必要はありません。

保存先は同じブラウザ・オリジンのlocalStorageです。別のブラウザ・端末・URLのポートとは共有されません。CrazyGames SDK、広告、クラウド保存、エンドレスは未実装です。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Viteが表示する `/survivor/` のURLを開いてください。`dist/` は本番ビルドです。

- `src/difficulty.js`：討伐数・出現密度・敵能力・ボスHP/報酬の調整表
- `src/arena.js`：討伐→予告→ボス→報酬→次の難易度の進行
- `src/progression.js`：収入倍率・永久セーブ
- `src/runSkills.js`：スキル効果・価格
- `src/spatial.js`：ループ境界の空間探索

開発ビルドのデバッグメニューでは、ボス出現条件の達成・敵全滅・無敵を使って各画面を確認できます。本番ビルドでは非表示です。

## 検証

永久スキルの購入条件・再計算・保存に加え、ボスの単独出現、重複報酬防止、5体目でのクリア、報酬画面からの強化、マップ・位置の維持、境界越しの命中・吸引・接触、通貨の金額固定と上限時の保全を自動テストします。

数値は試遊用の初期値です。初回強化までの時間・各ボスの撃破時間・再挑戦時の進み方を基準に今後調整します。
