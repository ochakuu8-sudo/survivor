# Stone Survivor — 固有武器ハクスラ版

壁のないループ平原で敵を倒し、固有武器を拾って育てるブラウザゲームです。武器1個に複数の効果を組み合わせ、5体のボスを倒すと完全クリアです。

## 遊び方

- WASD / 矢印キー、タッチ端末は画面ドラッグで移動。攻撃は自動です。
- Kで武器庫を開きます。戦闘中は閲覧のみ、装備交換・リロールは出撃前、ボス撃破後、結果画面で行えます。
- 通常敵の討伐数30 / 45 / 65 / 90 / 120で各難易度のボスが出現。時間では難易度が上がりません。
- ボス撃破でG、HP30%回復、武器3択。最終ボスも戦利品を選んでからクリアします。
- 死亡しても武器、経験値、装備、Gを引き継ぎます。戦闘は難易度1からやり直します。

## 武器と育成

固有武器72種類に初期装備の「原石」を加えています。同じ種類でも別個体として所持し、経験値・品質・アタッチメントが異なります。品質は威力90〜110%、入手後は固定です。

通常特性108個は36種類×3段階のアタッチメントに再編しました。Ⅰは入口効果、Ⅱ・Ⅲは同じ枝の追加効果まで含みます。素材やパーツ倉庫はありません。アタッチメントは武器に付いた効果です。

武器本体の効果と各枠の効果を、同じ石ころへ合成します。爆発しても貫通・跳弾・帰還は続きます。本体に内蔵済みの効果は重複加算せず、高い段階の追加分だけ有効です。同じ種類のパーツは複数枠に付けられません。

- 各個体はLv.1から開始。最大Lv.20。経験値はその武器を装備して敵を倒すと獲得します。
- 雑魚1、エリート5、ボス20を基本経験値とし、難易度ごとに1.6倍、整数に丸めます。派生攻撃による撃破も対象です。
- 次のレベルまでの必要経験値は `ceil(30 × 1.22^(現在Lv−1))`、基礎威力は `10 × 品質 / 100 × 1.12^(Lv−1)`。
- 初期3枠。Lv.4 / 8 / 12 / 16 / 20で4 / 5 / 6 / 7 / 8枠へ増加します。
- Gでレベルや枠を買うことはできません。既存パーツの段階も自動では上がりません。

## 武器ドロップとリロール

雑魚2%、エリート20%で武器を落とします。最初の武器がまだ落ちていない場合、10体目の撃破で保証します。落ちた武器は近づくと自動回収し、戦闘は止めません。未回収品は死亡・ボス撃破時にも回収します。

ボスは異なる武器種の3択です。初期3枠はランダムで、Ⅰ / Ⅱ / Ⅲの比率は難易度1から順に80/20/0、65/30/5、45/40/15、25/45/30、15/40/45%。武器種そのものは72種から均等に抽選します。

リロールは選んだ1枠だけが対象です。有効な候補を最大3種類提示し、1個を採用するか現在の効果を維持できます。通常価格は `round(15 × 1.2^(武器Lv−1)) G`。候補の段階は到達済み最高難易度の比率を使います。空き枠への初回候補提示は無料です。維持しても費用や無料提示権は戻りません。

**無料テスト設定は新規データでONです。武器庫のボタンで通常価格へ切り替えられます。** 経験値とレベル条件は無料設定でも有効です。無料設定はセーブごとに保持します。

所持上限96個。装備中・保護中・リロール中の武器は売却できません。満杯なら受取待ちに保存し、整理するまで進行を止めます。売却額は入手難易度×8＋パーツ段階合計×3 G。自動売却、経験値移植、装備消失はありません。

## セーブ

`survivor.progression.v4.weapon-loot` にG、全武器、装備個体、経験値、受取待ち、未回収品、ボス報酬候補、支払い済みリロール候補を保存します。リロードしても提示済み候補は変わりません。ラン途中の敵やボス戦の状態は再開しません。

v3またはv2から、解放済み特殊石をLv.1・品質100%の武器へ変換します。旧通常特性の有効な組み合わせを最大3枠へ移し、実支払済みの通常特性と共通基礎成長を返金します。旧セーブは変更せず、新形式保存後は再変換しません。旧保存構成も元データ側に残ります。

保存先は同一ブラウザ・オリジンのlocalStorageです。別端末、ブラウザ、ポートとは共有しません。CrazyGames SDK、広告、クラウド保存、取引、エンドレスは未実装です。

## 開発・検証

```sh
npm ci
npm run dev
npm test
npm run build
```

Viteの `/survivor/` を開きます。`dist/` は本番ビルドです。

- `src/lootModel.js`：武器・パーツ定義、個体、経験値、抽選、リロール、売却。
- `src/skillTree.js`：旧入口名を維持した武器庫UI。ツリー画面は撤去済み。
- `src/progression.js`：新セーブと移行。`legacyProgression.js` と旧モデルは互換処理・回帰テスト用。
- `src/stoneCombat.js` / `src/buildCombat.js`：複合弾、状態異常、派生効果。
- `src/arena.js` / `src/difficulty.js`：討伐・ボス・報酬の進行と数値。

個体別経験値、枠の境界、全武器とパーツ段階の戦闘、リロールの保存と支払い、抽選条件、満杯処理、移行の一回性、ループ境界、最終報酬を検証します。数値は初期試遊値で、武器ごとの最終バランス調整は今後の試遊を基準に行います。
