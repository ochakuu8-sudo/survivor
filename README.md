# Stone Survivor — ボス討伐・ループ平原版

敵を倒してGを集め、永久スキルツリーで石を強化するブラウザゲームです。壁や階段のない平原が上下左右につながります。

## 遊び方

- WASD / 矢印キーで移動。タッチ端末は画面ドラッグ。攻撃は自動です。
- K / 右下のスキルボタンで強化。ツリー表示中は戦闘が停止します。
- K / Escape / 戻るボタンでツリーを閉じます。
- 各難易度の討伐目標を達成すると、2秒の位置予告後にボスが出現します。
- ボス撃破でGを獲得し、落ちているGも全回収。HPを最大値の30%分回復します。
- 報酬画面で強化し、「次の難易度へ」で同じマップ・位置から再開します。
- 5体目のボス撃破で完全クリア。制限時間はなく、時間経過で難易度は上がりません。

ボス戦中は雑魚補充を減らします。ボス戦・出現予告中の討伐は次の難易度へ持ち越しません。後半のボスは予告付き突進に加え、方向を予告する扇状弾を使います。

## 難易度と経済（初期調整値）

| 難易度 | 必要討伐数 | 敵HP倍率 | 基準報酬倍率 | ボスHP | ボス報酬G |
|---|---:|---:|---:|---:|---:|
| 1 | 30 | 1 | 1 | 180 | 45 |
| 2 | 45 | 1.6 | 1.6 | 360 | 96 |
| 3 | 65 | 2.5 | 2.56 | 650 | 205 |
| 4 | 90 | 3.8 | 4.096 | 1050 | 430 |
| 5 | 120 | 5.5 | 6.5536 | 1650 | 983 |

通貨は整数に丸めます。ドロップ時に金額を確定するため、後から難易度を上げて回収しても値上がりしません。コイン上限に達すると価値をまとめ、消失を防ぎます。敵の通常移動速度は難易度5でも基準の1.32倍です。突進は予告付きの別行動です。

## 石ころを組み立てるスキルツリー

通常特性108個と特殊石72個の、接続された180ノードです。通常特性は習得するとすべて同じ石ころへ適用されます。連射・貫通・跳弾・帰還・爆発・追尾・属性を組み合わせられます。爆発は命中時の効果なので、爆発した石も跳弾や貫通を続けます。

特殊石は、表示された複数の通常特性を**すべて**習得すると自動解放されます。追加の購入は不要です。特殊石の装備は同時に1個。交換・返金・保存構成の読込は出撃前、ボス撃破後、結果画面で行えます。解放条件に必要な特性を返金すると、依存する特性も返金し、条件を失った特殊石は解除されます。

例：跳弾 → 遠跳び → 往復反射、命中爆発、連射弾倉を揃えると「爆連跳石」を解放。装備すると跳ねるたびに爆風が広がり、最後の跳弾で大爆発します。図鑑の「前提をまとめて習得」は既存の特性を残して不足分だけ追加します。保存構成の読込は特性も含めて振り直します。

公転は発射前の助走、帰還は復路、砲芯・地雷・震域は石ころの消滅位置から生じる効果です。砲芯の子弾も同じ特性を継承しますが、子弾は新しい砲芯・地雷を生成しません。破片の再分裂も止め、生成数と反応回数に上限を設けています。

デバッグ調整中につき `src/buildSettings.js` の `DEBUG_FREE_SKILLS = true` で通常特性はすべて0 G。新規データは習得0・所持0 Gで始まります。無効化した場合の通常特性は深さごとに10 / 25 / 60 G（最初の入口1個は無料）。共通の基礎成長は初回60 G、以降2.2倍、威力は1.25倍ずつ増加します。

## セーブ

所持G・習得特性・装備中の特殊石・保存構成は死亡・クリア・リロード後も保持します。戦闘は難易度1から再開します。保存先は `survivor.progression.v3.composed-stone`。直前のv2データから通常特性とGを引き継ぎ、旧大ノードの実支払額を返金します。特殊石の解放を再計算し、条件を満たす旧装備を最大1個引き継ぎます。旧データそのものは変更しません。

保存先は同じブラウザ・オリジンのlocalStorageです。別のブラウザ・端末・URLのポートとは共有されません。CrazyGames SDK、広告、クラウド保存、エンドレスは未実装です。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Viteが表示する `/survivor/` のURLを開いてください。`dist/` は本番ビルドです。

- `src/difficulty.js`：討伐数・出現密度・敵能力・ボスHP/報酬の調整表
- `src/arena.js`：討伐→予告→ボス→報酬→次の難易度の進行
- `src/progression.js`：収入倍率・永久セーブ
- `src/skillCatalog.js` / `src/stoneDefinitions.js`：特性・特殊石の解放条件・説明
- `src/buildModel.js`：習得・自動解放・装備・返金
- `src/stoneCombat.js`：共通の石ころの発射・命中・跳弾・帰還
- `src/buildCombat.js`：状態異常・反応・設置物
- `src/spatial.js`：ループ境界の空間探索

開発ビルドのデバッグメニューでは、ボス出現条件の達成・敵全滅・無敵を使って各画面を確認できます。本番ビルドでは非表示です。

## 検証

永久スキルの購入条件・再計算・保存に加え、ボスの単独出現、重複報酬防止、5体目でのクリア、報酬画面からの強化、マップ・位置の維持、境界越しの命中・吸引・接触、通貨の金額固定と上限時の保全を自動テストします。

数値は試遊用の初期値です。初回強化までの時間・各ボスの撃破時間・再挑戦時の進み方を基準に今後調整します。
